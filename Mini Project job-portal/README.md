# Job Portal (Full Stack)

A full-stack job portal application built using React (Vite) and Node.js.

## Features
- User authentication
- Job posting & application
- Dashboard for users
- REST API backend

## Tech Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: (your DB here, e.g. MongoDB)

## Installation

### Client
npm install
npm run dev

### Server
cd server
npm install
npm start
